# Hi, I'm Om

I build **local-first AI tools** and **interactive learning systems** that make complex ideas easier to understand and use.

My work spans applied machine learning, educational simulations, and small products built with Python, PyTorch, TypeScript, and JavaScript.

## Selected work

- **[TwistLab](https://github.com/OmTheLast/TwistLab)** — An interactive WebGL laboratory for learning twisty-puzzle notation, algorithms, and solving methods.
- **[Lumen](https://github.com/OmTheLast/Lumen)** — A local-first macOS desktop agent with local model discovery, voice support, and confirmation gates for risky actions.
- **[Drishya Physics](https://github.com/OmTheLast/Drishya)** — An interactive mechanics lab with a custom analytical solver and tests for energy and momentum conservation.
- **[Cross-Dataset Hinglish Hate Speech Research](https://github.com/OmTheLast/mBERT-vs-MuRIL-cross-dataset-hinglish-hate)** — A reproducible comparison of mBERT and MuRIL across code-mixed datasets, scripts, and label policies.
- **[Character-Level Transformer From Scratch](https://github.com/OmTheLast/character-transformer-from-scratch)** — A compact GPT-style language model implemented in PyTorch to understand every part of the training pipeline.
- **[Football Rule Cite](https://github.com/OmTheLast/DECISIONCITATION)** — A local retrieval-based assistant that explains referee decisions using evidence from the IFAB Laws of the Game.
