# Om Patnaik

I build local AI tools and study how language models behave, with a focus on browser systems, multilingual NLP, and careful evaluation.

[Portfolio](https://ompatnaik.com/) · [All projects](https://ompatnaik.com/projects.html)

## Featured research and systems

- **[LlamaJEE.js](https://ompatnaik.com/jee/)** — a browser-first local JEE solver and an experimental model archive. The case study separates fine-tuning tradeoffs from conversion checks. [Live solver](https://ompatnaik.com/llamajee/) · [Source](https://github.com/OmTheLast/LlamaJEE.js).
- **[Comparative Tokenizer Study](https://ompatnaik.com/tokenizers/)** — same-input token counts across model configurations and languages, with pinned assets and Python/JavaScript validation. [Source](https://github.com/OmTheLast/Tokenizer-estimation-study).
- **[mBERT vs MuRIL](https://ompatnaik.com/hinglish/)** — cross-dataset Hinglish harmful-speech research, including changing model rankings, missed positives, and failed mixtures. [Source](https://github.com/OmTheLast/mBERT-vs-MuRIL-cross-dataset-hinglish-hate).
